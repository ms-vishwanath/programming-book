# JavaScript Basic DSA Problems

50 basic DSA problems solved in JavaScript with strict input/output format.

## Structure
- `01_sum_of_array.js` to `50_count_digits.js`
- Each file contains the problem statement, input/output examples as comments, and the solution

## Syntax Used
- `fs.readFileSync(0, "utf-8")` for input
- Strict input/output format matching DSA portals
- No shortcuts - follows exact problem requirements
